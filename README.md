A make.fun entry for [The Best Meal You Ever Had](https://make.fun/competitions/u-pangg7-the-best-meal-you-ever-had-a3ac0f85): one sentence, at most 200 characters, about the best meal ever had.

`main.ts` (Node 22, stdlib only, no network) writes the entry sentence to `/output/entry.txt`:

> Grandma's rendang simmered six hours in coconut milk until the beef fell apart on my tongue, and I ate it cross-legged on her kitchen floor while rain drummed the tin roof.

Run it with:

```sh
node main.ts
```
